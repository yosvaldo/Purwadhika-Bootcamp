Pilih salah satu kode berikut dan copy paste ke dalam file index.ts
untuk simulasi kolaborasi menggunakan git.

```typescript
Tiara: const sum: number = n1 + n2;
console.log(`Hasil penjumlahan ${n1} + ${n2} = ${sum}`);

Gallant: const difference: number = n1 - n2;
console.log(`Hasil pengurangan ${n1} - ${n2} = ${difference}`);

Hendriawan: const multiplication: number = n1 * n2;
console.log(`Hasil perkalian ${n1} * ${n2} = ${multiplication}`);

Yosvaldo: const division: number = n1 / n2;
console.log(`Hasil pembagian ${n1} / ${n2} = ${division}`);

Dicky: const modulus: number = n1 % n2;
console.log(`Hasil modulus ${n1} % ${n2} = ${modulus}`);

Daiva: const exponentiation: number = n1 ** n2;
console.log(`Hasil perpangkatan ${n1} ** ${n2} = ${exponentiation}`);

Yulius: let n3: number = 10;
const increment: number = ++n3;
console.log(`Hasil increment ${n3} = ${increment}`);

Naufal: const sumAll: number = n1 + n2 + n3;
console.log(`Hasil penjumlahan semua ${n1} + ${n2} + ${n3} = ${sumAll}`);

Jovan: const average: number = sumAll / 3;
console.log(`Hasil rata-rata ${n1}, ${n2}, dan ${n3} = ${average}`);
```
